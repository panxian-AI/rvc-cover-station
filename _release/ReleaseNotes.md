# RVC 翻唱站 v1.0.3 · 白名单免审批直通

给**完全不懂代码**的人准备的版本：下载压缩包 → 解压 → 双击 `一键安装.bat` → 等它跑完 → 双击 `启动RVC.bat`。不想用了双击安装目录里的 `卸载程序.bat`。

## 下载

- **一键安装包**：`RVC-Cover-Station-Installer-v1.0.3.zip`（下方 Assets，约 6KB）
  内含 `一键安装.bat` 与 `安装说明.txt`；程序代码与依赖由安装器自动下载。

## 这一版的重点：自动跟着最新版本走

安装器不再写死某个版本快照，而是**每次运行都自动查询当前最新发布版本并按该版本安装**：

1. 先问 GitHub「最新 release 是哪个版本」，没被墙就直接问，被墙就走你测速选中的那条加速线路再问一次；
2. 拿到版本号（如 `v1.0.2`）后，下载**该版本**的代码包（`codeload/.../zip/refs/tags/v1.0.2`）；
3. 查不到版本号、或该版本的包拉不下来 → 自动回落 `main` 分支最新代码，不会卡在中间；
4. 解压后自动识别压缩包的根目录名（tag 包是 `rvc-cover-station-1.0.2`，main 包是 `-main`），两种都能正确整理成运行布局；
5. 安装完成的窗口里会打印「本次安装版本：vX.Y.Z」。

也就是说：**以后仓库更新代码、发了新 Release，你不用等新的安装包，用同一个安装器重跑就是最新版**（已装全的环境只会补模型，不会重装依赖）。

想固定装某个版本？用记事本打开 `一键安装.bat`，把顶部 `set "RVC_TAG="` 填成 `set "RVC_TAG=v1.0.2"` 即可，填了就不查最新、直接装这个版本。

## 它会自动做什么

1. **多线路测速**：对「直连 GitHub + 7 个常用加速前缀」逐条测速并显示耗时，自动选最快的；提示时回车用最快的，或输入编号手动换线；Python 安装包也会从官方源 / 华为云 / npmmirror 三镜像自动选最快；
2. **查询并下载最新版本代码**，整理成运行布局（`RVC-Data\{runtime, RVC-WebUI, RVCSVC}`）；
3. 安装内置 Python 3.12.10（只装在安装目录内，**不改系统设置**）；
4. 询问你的显卡：NVIDIA → 装 CUDA 12.8 版 torch；没有/不确定 → CPU 版；
5. 创建两个独立虚拟环境并装好全部依赖；
6. 下载基础模型与工具（rmvpe、小肥鱼声线、ffmpeg，约 270MB，全部按字节数校验）；
7. 生成启动入口 `启动RVC.bat`，并把 `卸载程序.bat` 一并放好。

磁盘需求：N 卡版约 12GB，CPU 版约 6GB。系统要求 Windows 10 1803 及以上。

## 卸载程序

双击安装目录里的 `卸载程序.bat`：
- 先停止正在运行的服务（3333 / 7865 / 8899 / 3002 / cloudflared）；
- 询问是否**保留个人数据**：翻唱成品、访客申请记录、网易云 Cookie 会移到旁边的「安装目录_卸载备份」文件夹，其余全部删除；
- 两次确认防误删，删除在后台完成后窗口自动结束。

## 下载地址自定义

- 固定线路（跳过测速）：`一键安装.bat` 顶部 `GH_PREFIX=` 填加速前缀；
- 固定版本：顶部 `RVC_TAG=` 填标签（留空 = 自动最新）；
- 备选线路 `GH_LINE2~8`、Python 三镜像、pip 源、torch 源全部可改。
