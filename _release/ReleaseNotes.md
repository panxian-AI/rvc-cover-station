# RVC 翻唱站 v1.4.0 · 静默启动 + 任务栏图标

## 这次改的是「看着难受」，不是「跑得慢」

以前双击 `启动RVC.bat`，桌面上会多一个 cmd 黑窗口，然后一直挂在那儿：

- 服务开好了，用户还得自己把它最小化；
- 手一抖关掉窗口，面板也跟着退出了；
- 装到别人电脑上，家里人看到一屏英文滚动，第一反应是「是不是中毒了」。

所以这版把窗口去掉了，但**没有把信息一起去掉** —— 这是静默化最容易踩的坑。

## 怎么做的

**1. 用 pythonw 当启动器**

`python.exe` 是控制台子系统程序，让它在窗口里跑，就必然有一个窗口。
`pythonw.exe` 是 GUI 子系统，天生没有控制台。

所以 `启动RVC.bat` 现在只做三件事：找到安装目录、找到解释器、
`start` 一下 `dashboard\launch_silent.py` 然后立刻退出 —— 窗口一闪（实测不到 1 秒）。

启动器（pythonw 下运行，全程无窗口）负责：

- 先看 8899 是否已经在跑 → 是就直接开浏览器，不再起第二个实例；
- 用一个命名互斥锁防「手快双击两次」：第二个启动器等第一个，不会两个进程抢端口；
- 体检解释器能不能真的执行（文件在 ≠ 能用，杀毒删剩半截很常见），
  不能跑就先跑一次 `fix_paths.py`（盘符变了的情况），还不行再报错；
- `DETACHED_PROCESS` 拉起面板，stdout/stderr 全部重定向进 `panel_console.log`；
- 轮询端口直到就绪（默认 45 秒，`RVC_SILENT_TIMEOUT` 可调），就绪后开浏览器。

**2. 出错不能静默**

窗口没了，报错也没了 —— 那才是最糟的体验。所以失败路径一律弹 Windows
原生消息框（`MessageBoxW`），把原因和下一步动作写清楚：

| 情况 | 消息框说什么 |
|---|---|
| 内置 Python 跑不起来 | 列三种常见原因（杀毒/安装中断/网盘同步），让重跑安装器 |
| 面板刚起就退出 | 多半 8899 被占：先双击「停止RVC.bat」再启动，附日志末尾 10 行 |
| 45 秒还没就绪 | 第一次要扫模型目录，让再等等；一直不行就停干净重来 |
| 找不到 panel.py | 安装不完整，重跑一键安装（模型不会重下） |

`RVC_NO_MSGBOX=1` 时不弹框（自动化测试、无人值守安装用），只写日志。

**3. 任务栏图标：黑窗口没了，得有个地方点**

面板启动后在通知区放一个紫色唱片图标（图标是代码画的 ICO，不额外下载文件）：

- **左键单击** → 菜单：打开控制台 / 打开安装目录 / 一键开启服务 /
  停止全部服务（面板留着） / 停止服务并退出面板
- **左键双击** → 直接打开控制台
- **右键单击** → 同一个菜单

托盘用 `ctypes` 直接调 `Shell_NotifyIconW` + 自建消息循环，**零第三方依赖**
（多装一个包就多一处装不上的可能）。菜单动作在后台线程跑，
点「一键开启服务」时图标不会卡住。

托盘起不来（远程桌面限制、无桌面环境）只写一行日志，网页控制台照常可用。

**4. 顺带堵掉其它会闪的黑窗口**

静默之后才注意到，这些地方只要进程没有控制台，Windows 就会给它们**新开**一个
黑窗口闪一下：

| 位置 | 什么时候闪 |
|---|---|
| `panel.py` 的 `os.system("")` | 面板启动，为了让控制台认 ANSI 颜色 |
| `uvr5/vr.py`、`mdxnet.py` 的 `os.system("ffmpeg ...")` | 分离出 mp3/flac 或需要重采样时 |
| `tunnel.py` 拉起的 `cloudflared` | 点「开启公网」时 |
| `panel.start()` 的 `os.startfile(bat)` 兜底 | 解释器缺失、退回跑 bat 时 |

全部改成 `CREATE_NO_WINDOW` / `SetConsoleMode`。兜底跑 bat 时还特意把 stdin
接空设备 —— 那些 bat 结尾的 `pause` 会立刻返回，不会留下一个看不见的进程
挂在那里等按键。

**5. 日志看得见**

- 控制台「服务状态」新增 **📜 启动日志**，点开就是 `panel_console.log`
  （原来黑窗口里的全部输出），每 8 秒自动刷新，超 2MB 轮转成 `.1`；
- 新增 `GET /api/panel_log`，本机可读；`/api/status` 多了 `silent` 和 `tray` 两个字段，
  页面据此显示「启动方式：静默 · 任务栏图标已就绪」；
- 面板的 `print` 在无控制台时不再炸：`input()` 改走 `_wait_enter()`（没有真控制台就不等），
  端口被占时的提示也改成了「双击停止RVC.bat」。

## 老用户要做什么

- **正常更新即可**，代码和 bat 会一起更新，第一次启动就是静默的；
- 想保留以前的带窗口启动：`启动RVC.bat --console`，或者 `set RVC_CONSOLE=1` 再双击；
- 不喜欢托盘图标：`set RVC_NO_TRAY=1`；
- 已经手动改过 `启动RVC.bat` 的话，这次会被覆盖（版本号变了，建议直接用新版）。

## 已知限制

- 静默模式下**关浏览器不会停面板**（以前关窗口会）。停面板请双击
  `停止RVC.bat`，或用任务栏图标里的「停止服务并退出面板」；
- 托盘在 Windows 通知区里可能被折叠进 `^` 里，需要自己拖出来固定一次；
- 面板被 `taskkill` 杀掉时来不及删图标，通知区可能残留一个「幽灵图标」，
  鼠标划过就消失（Windows 的已知行为，不影响功能）。

## 质量

- 回归 **16 套 729 项**全绿，新增 `dashboard/e2e_silent.py` 59 项：
  端口探测/日志轮转/GBK 日志/互斥锁/弹框抑制、ICO 生成与复用、真挂上通知区
