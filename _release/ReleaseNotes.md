# RVC 翻唱站 v1.0.6 · 版本检测 + 一键更新

控制台打开就自动查最新版；有新版本会弹窗列出更新内容，点一下就能更新——**只替换程序代码，模型、成品、访客记录、白名单、设置全都不动**。

## 下载

- **一键安装包**：`RVC-Cover-Station-Installer-v1.0.6.zip`（下方 Assets，约 8KB）
  内含 `一键安装.bat` 与 `安装说明.txt`；程序代码与依赖由安装器自动下载（长效模式：默认拉 main 最新）。

## 新功能：打开控制台自动检测版本

控制台首页新增「版本」卡片：

- 显示 **当前版本 / 最新版本**，状态标签是「已是最新」或「有新版本」；
- 每次打开控制台自动查一次（服务端缓存 10 分钟，不会把 GitHub 匿名额度用光）；
- 旁边有「🔄 检测更新」按钮，想立刻查就点它；
- 查不到（断网 / 代理不通 / GitHub 抽风）只会显示「检测失败 + 中文原因」，不影响听歌、制作和任何其它功能。

## 新功能：有新版本弹窗 + 一键更新

发现新版本会自动弹窗：

- 标题写明「发现新版本 vX.Y.Z（当前 vA.B.C）」；
- 正文是这一版的更新说明（标题 / 列表 / 表格都做了排版，不是一堆原始符号）；
- 底部三个操作：**在 GitHub 上看这一版** / **以后再说** / **⬆ 立即更新**。

点「立即更新」后：

1. 下载该版本源码包（直连 codeload + 7 个加速前缀自动换线，和安装器同一套线路）；
2. 按安装布局覆盖代码目录：`dashboard`、`RVCSVC-API`、`ncmapi`、`setup`、`RVC-WebUI`；
3. **绝不覆盖**：模型（`assets/weights`、`indices`）、成品库 `covers`、`guest_db.json`、`advanced_settings.json`、网易云 Cookie、日志、`apivenv` 虚拟环境、`temp/output` 缓存；
4. 覆盖前把要改的文件备份到 `_update_backup/时间/`，出问题能手工找回；
5. 版本号写进安装目录的 `VERSION`，更新完不会再提示同一版；
6. 提示「重启面板生效」——关掉窗口重新双击 `启动RVC.bat` 就是新版（依赖没变，不用重装）。

安全细节：更新包解压时逐条校验落点，`..` 越界路径会被拦掉；只认上面那五个代码目录，包里的其它文件一律不落地。

## 版本号怎么来的

- 仓库根新增 `VERSION` 文件（当前 `1.0.6`），安装目录里也有一份；
- 最新版本取 GitHub Releases 的最新一条（所以每发一次 Release 就等于给所有用户推送了一次更新）；
- 老安装（没有 `VERSION` 文件）会回落到代码内置的版本号，不会报错。

## 怎么用上这一版

- **已经装了 1.0.5 及更早**：那个版本还没有检测模块，重跑一次安装目录里的 `一键安装.bat`（默认拉 main 最新代码）即可；从这一版开始，以后在控制台里就能自己更新，不用再动安装器。
- **全新安装**：下载本页 Assets 的安装包，双击 `一键安装.bat`。
