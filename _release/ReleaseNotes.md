# RVC 翻唱站 v1.2.1 · 启动提速 + 并行启动 + 文档全量更新

这版是个小更新，主题就一个字：**快**。外加把之前一直欠着的说明文档全部补齐。
更新方式照旧：面板会提示新版本，点更新即可（模型、成品、配置都不会动）。

## 1. 后端启动从约 20 秒降到约 7 秒

**症状**：每次点开服务，3333 后端都要等 20 秒上下才就绪，其中大半时间
机器看起来「什么都没干」。

**真因**：启动阶段有两笔白付的钱——

- `import torch` 要 10 秒以上，但启动阶段一处都用不到：设备检测只在
  「分离模型现场加载」时才需要，清显存只在任务结束后才需要；
- `from uvr5.vr import AudioPre` 写在模块顶层，会连带把 torch、librosa
  整条链拖进来（v1.2.0 只把**实例**改成了按需加载，**导入**还是启动就执行）。

**改法**：两处都推迟到第一次真正用到时再导入。启动阶段一个重模块都不碰，
「一键开启」里后端几乎瞬间就绪。

**老用户怎么办**：什么都不用做，行为完全兼容；第一个翻唱任务会多花约 10 秒
（现场导 torch），之后无感。

## 2. 「一键开启服务」改为三路并行

以前是串行：等 WebUI(7865) 就绪 → 再起后端(3333) → 网易云。总耗时等于
「WebUI + 后端」相加。现在 WebUI、后端、网易云**同时拉起**，总耗时变成
「最慢的那一个」，一般省 15~30 秒。

配套改动：

- 3333 打开页面时会**自动拉一次模型列表**，WebUI 晚就绪也不会出现
  「模型下拉框空着」；
- 单独点 3333 的「启动」不再被「WebUI 还没就绪」拦截（WebUI 没起时
  换声任务会报可读的错误提示）；
- 停止顺序不变：还是先后端 → 网易云 → 最后 WebUI。

## 3. 说明文档全量更新

README 与 `docs/使用说明.md` 此前缺了 v1.2.0 的三块新功能说明，这次全部补上：

- **模型管理页**（`/models`）：声线列表、索引配对、孤儿索引、两段式删除；
- **模型按需加载**：分离器不再开机常驻内存，`RVC_UVR_IDLE_UNLOAD` 可调；
- **导入区就地「🔄 更新声线」**：导完模型不用跳市场页刷新；
- 本版的启动提速与并行启动说明。
- 顺手修正：回归测试数从「11 套 529 项」更正为「13 套 592 项」。

## 老用户更新方式

1. 打开控制台（http://127.0.0.1:8899），等它弹出「发现新版本 v1.2.1」，点更新；
2. 更新完**关掉面板窗口，重新双击「启动RVC.bat」**（面板进程要重开才能
   用上新的并行启动逻辑；WebUI/后端不受影响，正在跑的任务不会被中断）。
