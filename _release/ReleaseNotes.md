这一版解决两个「一直很烦」的事：**找不到声线模型**，和**更新时卡在某条线路上一直转圈**。

## 下载

- **一键安装包**：`RVC-Cover-Station-Installer-v1.1.0.zip`（下方 Assets，约 8KB）
  内含 `一键安装.bat` 与 `安装说明.txt`；程序代码与依赖由安装器自动下载（长效模式：默认拉 main 最新）。
- 已经装过的：控制台打开会提示有新版本，点「立即更新」即可，**模型 / 成品 / 访客记录 / 白名单 / 设置都不动**。
  这一版的更新器自己就会先给 8 条线路测速、挑最快的下。

## 一、模型市场（新页面 `/market`）

控制台右上角多了「🧩 模型市场」——不用再去网站上手动找 `.pth`、下载、解压、点导入。

**能搜什么**

| 来源 | 内容 |
| --- | --- |
| 模型库 | HuggingFace 上 RVC 社区的公开声线仓库，按下载量 / 喜欢 / 更新时间浏览 |
| 合集包 | 社区上传的「模型合集」，一个包里有几十上百个声线（实测有 338 个 `.pth` 的包） |

走的是这两个站点的**公开 JSON 接口**（把网页上的列表和文件清单读下来），只保留真正带 `.pth`
且判定为语音转换类的仓库：有 `.index`、或带 `rvc` / `voice-conversion` 标签、或名字含 rvc/voice；
`gated`（要登录同意条款）、私有、纯 LLM 权重的仓库会被过滤掉。搜索有 5 分钟缓存，热门词一键点。

**下载：先测速再下，失败自动换线**

- 每条线路对**真实文件**用 Range 实探 128KB，按实测速度排序后从最快的开始；
- 线路：`hf-mirror.com`（国内镜像，通常最快）+ `huggingface.co`（官方兜底），上次成功的线路会被记住；
- 支持**断点续传**（`.part`），取消后下次接着传；下完的文件留在 `_market_cache/`，重装不再重复下载；
- 想加自建反代：`RVC_MARKET_LINES="镜像A=https://a.example.com,镜像B=https://b.example.com"`。

**核验：三道全过才装**

1. **大小**必须和站上公布的一致；
2. **SHA-256** 逐字节比对（HuggingFace 对每个 LFS 文件都给了哈希），不符直接丢弃；
3. **结构**：`torch.load(weights_only=True)` 读到 `weight` 里的 `enc_p.*` 特征层才算 RVC 声线；
   `.index` 必须 `Iw`/`Ix` 开头（faiss 魔数）。

装完提示重启 3333 后端；控制台的市场卡片会显示「已装几个、几个带索引」。

**真机实测**：`TogetsuDo/amiya-rvc` 52.6MB 声线，测速选中镜像线，约 65 秒下完 →
SHA-256 通过 → torch 结构核验通过 → 装进 `assets/weights`，文件名保持 `amiya.pth`（不带仓库前缀）。

## 二、在线更新：8 条线路先并行测速

以前是「按固定顺序逐个试」，遇到半死的加速镜像要干等 60 秒超时才换线，体感就是「点了更新一直转圈」。

现在：

- 先把 8 条线路（GitHub 直连 + 7 个常用加速前缀）**并行实测**（各探 128KB），按速度排序；
- 从最快的开始下，失败自动降级到下一条；全部失败才报中文原因；
- 更新完成的提示里会写明「走的哪条线、实测多少 KB/s」。

## 三、顺手改的

- 模型市场下载的缓存文件带仓库前缀，装机时会按**仓库里的原始文件名**落盘
  （`install()` 新增可选 `name` / `index_name`，老调用方式不变）；
- 核验阶段文案改成「核验模型结构（torch 读权重，约 10~30 秒）」，不再像卡住；
- 安装说明 / README / docs 同步补了模型市场的来源、线路、核验与合规说明。
