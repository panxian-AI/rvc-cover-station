控制台新增「高级设置」卡片：翻唱参数不用再改代码，同时制作数量也能随时调。已装好的环境只需更新代码（见文末），不用重装依赖、不用重下模型。

- **一键安装包**：`RVC-Cover-Station-Installer-v1.0.5.zip`（下方 Assets，约 8KB）

  安装器本身沿用 v1.0.4 的**长效模式**：默认拉取 main 分支最新代码，以后不需要跟着发 Release。

## 新功能：高级设置

控制台首页新增一张卡片，改完点「💾 保存设置」立即生效（写进 `dashboard/advanced_settings.json`，重启后仍在）：

**① 同时制作数量（1~6）**
- 默认 1：排队逐个做，最稳；
- 调大可以让多单并行，队列里批准的单会一次开跑 N 单；
- 每路都分显卡算力，单首会更慢；显存 <8G 建议 1~2；
- **改完不用重启**：下一次推进队列就按新上限放行，在跑的单不受影响。

**② 成品默认翻唱参数**

| 项目 | 说明 |
|---|---|
| 音高算法 | rmvpe（推荐）/ crepe（更准更慢）/ harvest / pm（最快） |
| 声线检索强度 | 0~1，一般 0.6~0.8，太高压出电流声 |
| 音高滤波半径 | 0~7，越大音高越稳但咬字僵 |
| 混响强度 | 0~10，0 = 干声，4 = 默认 |
| 回声强度 | 0~10，0 = 关 |
| 人声分离聚合度 | 0~20，越高人声越干净、伴奏剔得越狠 |
| 人声音量 / 伴奏音量 | -10~+10 dB，0 = 不调整 |

参数在**每一单真正开跑前**读一次，所以改设置对还没开始的任务立刻生效；已经在跑的那单不受影响。所有值都有范围校验：超范围自动夹到边界、填错类型或算法名自动回落默认，并给出中文提示；「恢复默认」一键还原。

## 顺手修的细节

- 队列区显示「正在做 2/3 单」，多单并行时一眼看清谁在做；
- 并发位用「占位-还位」实现，任务失败/卡死也会还位，不会把上限卡死；
- 设置文件写坏（非法 JSON）也不会让面板崩，自动回落默认值。

## 已装好的怎么更新

1. 双击安装目录里的 `一键安装.bat`：它默认拉 main 分支最新代码，会自动补齐/覆盖程序文件；
2. 或者等你下次重装时直接用新版安装器；
3. 更新后**重启面板**（关掉窗口再双击 `启动RVC.bat`），新设置卡片就出现了；
4. 依赖没变，已有模型、成品、访客记录、白名单都不会动。
