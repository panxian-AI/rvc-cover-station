# RVC 翻唱站 v1.0.4 · 长效安装器

给**完全不懂代码**的人准备的版本：下载压缩包 → 解压 → 双击 `一键安装.bat` → 等它跑完 → 双击 `启动RVC.bat`。不想用了双击安装目录里的 `卸载程序.bat`。

## 下载

- **一键安装包**：`RVC-Cover-Station-Installer-v1.0.4.zip`（下方 Assets，约 8KB）
  内含 `一键安装.bat` 与 `安装说明.txt`；程序代码与依赖由安装器自动下载。

## 这一版的重点：长效支持未来版本

安装器改为**默认下载仓库 main 分支的最新代码**（此前是查询最新 release 的 tag）：

1. 不再需要每次更新都同步发一个 Release——代码一提交到 main，重跑安装器就是最新版；
2. 少一次「查最新版本号」的联网步骤，安装更快一步到位；
3. 仍可锁定旧版本：用记事本打开 `一键安装.bat`，把顶部 `set "RVC_TAG="` 填成 `set "RVC_TAG=v1.0.3"`，锁定的版本下载失败时也会自动改用 main 分支，不会卡住。

也就是说：**这个安装器装一次就够了，以后程序怎么更新它都跟得上**（已装全的环境只补模型，不会重装依赖）。

## 这一版的重点：弹窗选安装位置

双击 `一键安装.bat` 后会先弹出 **Windows 标准的文件夹选择窗口**：

- 窗口里可以直接**新建文件夹**再选中；
- 窗口被挡住时去任务栏找一下；
- 不想用窗口就直接关掉，自动改为手动输入路径（直接回车 = 默认位置）；
- 依旧拒绝 C 盘根目录等不合适的位置，防手滑。

## 它会自动做什么

1. **弹窗选安装位置**（如上，可关闭窗口改手动输入）；
2. **多线路测速**：对「直连 GitHub + 7 个常用加速前缀」逐条测速并显示耗时，自动选最快的；提示时回车用最快的，或输入编号手动换线；Python 安装包也会从官方源 / 华为云 / npmmirror 三镜像自动选最快；
3. **下载 main 分支最新代码**（或锁定的 tag），整理成运行布局（`RVC-Data\{runtime, RVC-WebUI, RVCSVC}`），解压后自动识别压缩包根目录名；
4. 安装内置 Python 3.12.10（只装在安装目录内，**不改系统设置**）；
5. 询问你的显卡：NVIDIA → 装 CUDA 12.8 版 torch；没有/不确定 → CPU 版；
6. 创建两个独立虚拟环境并装好全部依赖；
7. 下载基础模型与工具（rmvpe、小肥鱼声线、ffmpeg，约 270MB，全部按字节数校验）；
8. 生成启动入口 `启动RVC.bat`，并把 `卸载程序.bat` 一并放好。

磁盘需求：N 卡版约 12GB，CPU 版约 6GB。系统要求 Windows 10 1803 及以上。

## 卸载程序

双击安装目录里的 `卸载程序.bat`：
- 先停止正在运行的服务（3333 / 7865 / 8899 / 3002 / cloudflared）；
- 询问是否**保留个人数据**：翻唱成品、访客申请记录、网易云 Cookie 会移到旁边的「安装目录_卸载备份」文件夹，其余全部删除；
- 两次确认防误删，删除在后台完成后窗口自动结束。

## 下载地址自定义

- 固定线路（跳过测速）：`一键安装.bat` 顶部 `GH_PREFIX=` 填加速前缀；
- 固定版本：顶部 `RVC_TAG=` 填标签（**留空 = 长效模式，跟 main 分支最新**）；
- 备选线路 `GH_LINE2~8`、Python 三镜像、pip 源、torch 源全部可改。
