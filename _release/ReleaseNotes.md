# RVC 翻唱站 v1.0.0 · 一键安装版

给**完全不懂代码**的人准备的版本：下载下面的压缩包，解压，双击 `一键安装.bat`，等它跑完，再双击 `启动RVC.bat` —— 就能用了。

## 下载

- **一键安装包**：`RVC翻唱站-一键安装包-v1.0.0.zip`（下方 Assets，约 10KB）
  里含 `一键安装.bat` 与 `安装说明.txt`；安装器会自动去下载程序代码与依赖。
- 下载慢/失败：国内可先给安装器顶部 `GH_PREFIX` 填一个加速前缀（如 `https://ghfast.top/`），或换任意自选下载地址。

## 它会自动做什么

1. 下载本仓库代码并整理成运行布局；
2. 安装内置 Python 3.12.10（只装在安装目录内，**不改系统设置**）；
3. 询问你的显卡：NVIDIA → 装 CUDA 12.8 版 torch；没有/不确定 → CPU 版；
4. 创建两个独立虚拟环境并装好全部依赖（面板层 + 翻唱后端 + RVC-WebUI）；
5. 下载基础模型与工具（rmvpe、小肥鱼声线、ffmpeg，约 270MB，全部按字节数校验）；
6. 生成启动入口 `启动RVC.bat`。

磁盘需求：N 卡版约 12GB，CPU 版约 6GB。系统要求 Windows 10 1803 及以上。

## 装完怎么用

1. 双击 `启动RVC.bat` → 浏览器打开监控面板 `http://127.0.0.1:8899`；
2. 面板首页点「一键开启全部服务」；
3. 本机自用即可开始翻唱；想让朋友用，见面板「公网地址」或文档《使用说明.md》。
4. 可选：网易云歌曲功能 → 双击 `RVC-Data\RVCSVC\ncmapi\设置网易云Cookie.bat`。

## 下载地址自定义

「一键安装.bat」顶部「下载地址配置区」全部可改：仓库来源、GitHub 加速前缀、
Python 安装包地址、pip 镜像源、torch 下载源。修改后保存重跑即可，重跑是安全的（自动断点续装）。
