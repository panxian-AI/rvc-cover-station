# RVC 翻唱站 v1.2.0 · 模型管理页 + 模型按需加载 + 导入区刷新键

这版是给「声线越装越多」的用户准备的：装多了之后，找模型、删模型、内存吃紧
这三件事一起解决。更新方式照旧：面板会提示新版本，点更新即可（模型、成品、
配置都不会动）。

## 1. 新增「模型管理」页（导航里多了这一项）

以前声线装进 WebUI 之后就「看不见」了——不知道装了哪些、哪个占多大、配套
索引在不在，想删还得自己去翻文件夹。

现在打开 http://127.0.0.1:8899/models 就能：

- 看到**所有已装声线**：名字、大小、导入时间，有没有配套索引（有索引音色更准）；
- 按**名字过滤**（装了十几个之后很有用）；
- **删除**声线：先弹确认框列出会删哪些文件、腾多少空间，确认后才动手，
  配套索引可以连着一起删；
- 「孤立索引」（声线已删但索引还留着的）单独列出来，缺空间时可以清。

删除只动 weights / indices 目录里的模型文件，成品库、缓存、配置一概不碰。

## 2. 分离模型改成「按需加载」，声线多、内存紧的机器不白占

以前 3333 后端一启动，就把人声分离模型（UVR5）装进内存，几百 MB 从开机
白占到天荒地老——哪怕你接下来只是想点歌听听。

现在：

- 启动**不再预载**任何分离模型，启动更快、内存更省（实测启动日志干净了很多）；
- 第一个需要分离的任务**现场加载**（日志会打「⏳ 按需加载人声分离模型」，
  首个任务会多花几秒，之后就走缓存）；
- 空闲 **15 分钟**自动释放，把内存让给后面的任务（想改时长或关掉这个行为，
  设环境变量 `RVC_UVR_IDLE_UNLOAD`，单位秒，0 = 从不卸载）。

RVC 声线模型本来就是用到哪个才加载哪个（一次只驻留一个），这次补齐的是
分离模型这块。

## 3. 模型导入区直接加「🔄 更新声线」，不用再去模型市场

以前在控制台导入完模型，得跳去模型市场页点右上角的更新按钮。现在导入区
旁边就有「🔄 更新声线（重启后端）」：点一下让 3333 重启并重扫模型目录
（约 30~90 秒），新声线立刻进点歌列表。判定标准和市场页一致——端口
「先关后开」才算成功，失败会给原因。
