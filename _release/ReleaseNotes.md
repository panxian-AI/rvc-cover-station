# RVC 翻唱站 v1.4.1 · 开启服务不再弹终端 + 控制台可见自助翻唱任务

小更新两件事，都是上一版收尾没做干净的地方。

## 一、点「一键开启服务」，桌面不再冒出三个终端

**症状**：上一版双击 `启动RVC.bat` 已经不挂黑窗口了，但点「⚡ 一键开启服务」之后，
桌面会接连冒出三个终端窗口（大概率是 Windows Terminal 的标签页），标题是一串
解释器路径，得一个个手动关。

**真因**：三个服务是用 `python.exe` 起的。`python.exe` 属于**控制台子系统**，
进程一创建就要一个控制台。旧代码传的是 `DETACHED_PROCESS`（本意是「别继承父进程
的控制台」），在 Win10 上确实够用 —— 但 **Win11 把 Windows Terminal 设成「默认
终端应用」** 之后，这类进程会被 WT 接过去开一个标签页，`DETACHED_PROCESS` 挡不住。

**改法**：改用同目录的 **`pythonw.exe`** 启动服务。它是 GUI 子系统程序，创建进程
时根本不申请控制台，桌面上不可能再出现窗口。同时把另外两层保险也补齐：

| 层 | 做法 | 作用 |
|---|---|---|
| 进程本体 | `pythonw.exe` | GUI 子系统，不申请控制台（真正解决问题的这一层） |
| 创建标志 | `DETACHED_PROCESS` + `CREATE_NO_WINDOW` + `CREATE_NEW_PROCESS_GROUP` | 老机器 / 回退到 python.exe 时兜底 |
| 启动信息 | `STARTF_USESHOWWINDOW` + `SW_HIDE` | 再兜一层，某些终端宿主会看这个 |

日志一个字都没丢，因为本来就是重定向进文件的：后端 → `api_rvc_panel.log`，
WebUI → `logs\webui_service.log`，网易云 → `ncm.log`。公网隧道（cloudflared）
走同一套标志。

顺手修掉网易云服务里两处会「闪一下黑框」的老代码：`os.system("")`（本来是借它
打开 ANSI 颜色）改成 `SetConsoleMode`；`ipconfig` 加上 `CREATE_NO_WINDOW`。

**实测**（本机 Win11 + Windows Terminal 默认终端）：改前点一次开启 = 桌面多 3 个
终端窗口；改后新增窗口 **0 个**，三端口照常就绪，日志照常写。

## 二、自助翻唱的任务，总面板也能看到

**症状**：在「🎤 自助翻唱」（`/cover`）页下单，控制台的「制作队列」永远是空的 ——
因为那一块读的是**访客**队列。想看进度得切回翻唱页，做完才知道结果。

**真因**：自助翻唱是站长自己用的入口，任务只活在 `cover.py` 的内存表 `_jobs` 里，
从来不写访客队列，控制台也就没有它的数据源。

**改法**：新增 `GET /api/cover/jobs`（只认本机直连），一次给全三类状态；
控制台「制作队列」下面多一张 **「🎤 自助翻唱任务」** 卡片：

- **正在做**：标题 / 声线 / 升降调 / 清唱，加上**当前阶段**（派发任务、归档成品）
  和**已用秒数**；
- **排队**：GPU 满时排在后面的单，按顺序列；
- **最近完成**：最近 5 单，成功的点 **▶ 试听**，失败的显示原因。

跟着控制台每 8 秒自动刷新，不用手动点。

## 老用户怎么拿到

控制台会自己提示新版本（也可以点「版本」那块的手动检查），一键更新即可 ——
只动代码，模型、成品、访客记录、白名单、设置都不碰。

更新完**要重开一次面板**（托盘菜单「停止服务并退出面板」，或双击 `停止RVC.bat`
再启动）：面板进程是常驻的，不重启还是旧代码，服务也还是用旧方式拉起。
托盘图标、静默启动、启动日志这些上一版的东西都不变。

## 回归测试

16 套 **753 项**全绿（比上一版多 24 项，新增在 `e2e_silent.py` 的 D 段）：

- 服务确实用 `pythonw.exe` 起、三处拉起共用同一套无窗口标志、隧道也隐藏；
- `ncm_proxy.py` 里不许再出现 `os.system(...)`（用 AST 查，不看注释）、
  `input()` 只剩一处且包在 `isatty` 里；
- 快照分类正确：running / queued / recent 三段，recent 只留最近 5 条且按完成时间
  倒序，total 只算未完成的，模型名去掉 `.pth`；
- 控制台页面确实有卡片、`refresh()` 里确实调了它、接口在本机校验**之后**
  （外网拿不到）。
