# RVC 翻唱站 v2.1.5 · 网易云扫码登录直接内嵌在控制台

> **症状**：网易云「未登录」那个黄标签一直挂着，VIP / 独家曲目搜不到，
> 提示让你去 `RVCSVC\ncmapi\` 双击一个 bat —— 大多数人根本走不到那一步，
> 或者以为站点坏了。偶尔真去双击了，还得关掉独立窗口、再回浏览器刷新。
>
> 这一版把登录搬进控制台：概览页点一下「扫码登录」，二维码就画在页面上，
> 手机扫完确认，**当场生效**，不用重启任何服务。

---

## 一、为什么以前这么难

网易云的登录态本质就是一条 `MUSIC_U` Cookie，存在
`ncmapi\ncm_cookie.txt` 里，3002 的网易云代理启动时读一次。

老流程是这样的：

1. 面板提示「未登录：双击 `RVCSVC\ncmapi\设置网易云Cookie.bat`」；
2. 用户得自己去安装目录里找到那个 bat（很多人根本不知道装在哪）；
3. 双击后弹出一个 tkinter 小窗口，扫码；
4. 扫完窗口留着，用户再切回浏览器自己刷新。

这四步里任何一步断掉，结果都是「标签一直黄着」。而它只影响 VIP 和独家
曲目，普通歌照样能搜到——所以更容易被当成「网易云接口又不稳了」。

## 二、这一版怎么改的

**1. 扫码登录内嵌进概览页（主入口）**

概览页「服务状态」卡片里，网易云那一行下面多了一排：

```
📱 扫码登录网易云     还没登录（只能搜到免费曲目）
```

点开是一个页面内弹层（不是新窗口）：二维码、状态提示、换一张、退出登录、
以及折叠起来的「粘贴 Cookie（备选）」。全在本页，扫完直接看到
「✅ 登录成功：昵称」，卡片上的黄标签同时消失。

- 二维码每 2 秒问一次状态：等待扫码 → 已扫码待确认 → 成功 / 过期。
- 弹层关掉就停止轮询，不会在后台一直打网易云接口。
- 网络抖一下不会把二维码作废，下一轮继续问；只有 800（过期）才要「换一张」。

**2. 二维码是现画成 SVG 的，不落图片文件**

页面里显示的是 `<svg>`，不是 PNG。生成逻辑仍然是那个纯标准库编码器
（`ncmapi/_qr.py`，和参考实现逐位一致、能过 cv2 解码），这版加了
`to_svg()`：一条 path 画完所有黑模块，版本 5 的码不到 4KB。
不装 qrcode / PIL / segno，离线也能出码。

**3. 登录逻辑从窗口里抽出来（`ncmapi/ncm_login.py`）**

扫码的网络部分（申请 unikey、轮询、取昵称、落盘）不再长在 tkinter 文件里，
面板和独立窗口共用同一份：

- 行为一致：两边解析粘贴内容、错误话术、写盘格式完全相同；
- 面板不用为一个登录功能去 import tkinter；
- 独立窗口 `设置网易云Cookie.bat` **仍然可用**，只是从主入口变成备选入口。

**4. 落盘改成原子的**

以前是 `open(..., "w")` 直接覆盖。写到一半断电 / 进程被杀，文件里就是半个
Cookie：代理读到的值不可用，而界面还显示「已登录」。现在先写 `.tmp`、
`fsync`、再 `os.replace`——最坏情况是旧文件原封不动。

**5. 「退出登录」也能在页面上点了**

以前要手动删文件。现在弹层右下角有「退出登录」，删掉 Cookie 后代理立刻
退回匿名模式（同样按 mtime 热更新）。

## 三、不用重装，也不用重开浏览器标签

- 这一版改的是 `dashboard\`（面板）和 `ncmapi\`（代理旁边的登录模块），
  **数据和模型一个字都没动**。
- 面板进程要重启才会加载新页面和路由：双击根目录 `停止RVC.bat`，
  再双击 `启动RVC.bat`，然后刷新一下浏览器。
- 3002 网易云代理不用动：它本来就按 `ncm_cookie.txt` 的修改时间热加载，
  扫码成功那一刻就生效了。
- 登录态是账号级的，换机器要重新扫一次；同一个人多开几个面板实例共用一份
  Cookie，不用重复登录。

## 四、更新方式

控制台「版本」卡片点「检查更新」→「立即更新」，或在 Release 页面下载
`RVC-Cover-Station-Installer-v2.1.5.zip` 覆盖安装（不会动你的成品、声线、
访客库）。

更新完同样要重开一次 `启动RVC.bat`——更新逻辑在 `updater.py` 里，Python
只在启动时加载模块。
