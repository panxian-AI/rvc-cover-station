## RVC 翻唱站 v1.1.2 · 修好「装不上、启动闪退、停不干净」

这版没有新功能，全是在别人机器上真实踩到的坑：**双击启动一闪而过**、
**安装时弹「此应用无法在你的电脑上运行」**、**点了停止端口还在监听**。

三个问题都已修掉。已经装好的用户不用重装——重跑一次安装器或让程序自更新即可。

---

### 1. 启动「窗口一闪就没」→ 自适应路径 + 失败不再闪退

**原因**：启动脚本假定「它旁边就是 `RVC-Data`」「`runtime` 下有 `fix_paths.py`」。
装到别的盘、文件夹改过名、或文件被挪动过，就会走进报错分支；而窗口一闪而过，
用户什么原因都看不到，只会以为程序坏了。

**现在**：

- **自适应找根目录**：本级 / `RVC-Data` / 上一级 / 上一级的 `RVC-Data`，
  以「含 `runtime\python312\python.exe` 的那层」为准，装在哪、叫什么名都认；
- `fix_paths.py` 也改成逐层向上找运行时（原来它写死「我在 `runtime` 下」，
  从 `setup` 目录跑会算出错误的根，必失败）；
- 启动前先探测两个 `python.exe` **真能执行**——文件存在不等于能用
  （杀毒删剩半截、安装中断、网盘同步损坏都会坏）；
- 任何一步失败都写同目录 `_启动日志.txt` 并停住等按键，**不再闪退**；
- 顺手修掉日志的 `echo x=5>>log` 写法：`5>>` 会被 cmd 当成句柄重定向，
  日志丢值、路径还可能被吃掉一个字符。

### 2. 安装时弹「此应用无法在你的电脑上运行」→ 校验 Python 安装包

**原因**：安装器下载 `_py.exe` 后只检查 curl 有没有报错，不检查下到的是什么。
CDN / 代理抽风时会返回一段 HTML 错误页（几十 KB），照样存成 `.exe` 拿去运行，
Windows 弹的正是这个框。

**现在**：下载后先校验大小（**<10MB 判定为错误页**，正版安装包约 25MB），
自动换 **python.org / 华为云 / npmmirror** 三个镜像重试，不再拿错误页当安装器。

### 3. 「一键停止」停不干净 → 全杀 + 关隧道 + 停不掉不装退出

**三个漏洞**：

1. 端口映射用 `setdefault`，**每个端口只记第一个 PID**。Windows 允许两个进程同时
   监听同一端口，所以只杀得掉一个，剩下的继续占着；
2. `stop_all()` 只管 3333 / 3002 / 7865。`cloudflared` **不监听本地端口**，
   按端口永远找不到——面板关了、公网地址还挂着；
3. `shutdown` 不管成败都 `os._exit(0)`。没停干净面板也走了，用户再也点不到停止，
   只能去任务管理器——这就是「没办法真正退出」。

**现在**：

- 端口上**所有**监听进程一起收，`taskkill /T` 杀整棵进程树，两轮复查 + 补杀；
- 停止前强制重读 netstat（原来 4 秒缓存会漏掉刚叠上来的实例）；
- 停不干净就**如实报**「端口 7865 仍被 PID xxxx 占着」，并**不退出面板**；
- 退出时一并关掉公网隧道；
- 新增 **`停止RVC.bat`**（安装目录根下）：不依赖面板，面板已关也能按端口清干净，
  支持 `--dry-run` 先看会停谁；
- 控制台的「⏹ 全部停止」保持只停服务、保留面板与隧道（语义是「先别关，我还要看」）；
- 端口卡片对「多进程抢同一端口」显示黄色警告。

### 4. 面板重复启动不再叠加实例

`allow_reuse_address = True` 在 Windows 上不是「快速重启」，而是**允许抢占已占用端口**。
重复双击启动脚本会叠出多个实例同时 accept 8899，请求随机落到某一个——
于是同一个地址时而正常时而 404（新增页面「看不见」就是这么来的）。

现改为独占：第二个实例直接 `WinError 10048`，提示「面板已在运行」并自动打开它。

---

**升级方式**：重跑一次 `一键安装.bat`（长效安装器默认拉 main 最新代码，
只覆盖程序，不动模型 / 成品 / 白名单 / 设置）。
