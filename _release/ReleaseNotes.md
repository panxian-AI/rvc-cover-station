# RVC 翻唱站 v1.0.1 · 测速选线 + 卸载程序

给**完全不懂代码**的人准备的版本：下载下面的压缩包，解压，双击 `一键安装.bat`，等它跑完，再双击 `启动RVC.bat` —— 就能用了。不想用了就双击安装目录里的 `卸载程序.bat`。

## 下载

- **一键安装包**：`RVC-Cover-Station-Installer-v1.0.1.zip`（下方 Assets，约 5KB）
  里含 `一键安装.bat` 与 `安装说明.txt`；安装器会自动去下载程序代码与依赖。

## 它会自动做什么

1. **多线路测速**：对「直连 GitHub + 7 个常用加速前缀」逐条测速并显示耗时，
   自动选最快的线路；提示时回车用最快的，或输入编号手动换线；
   Python 安装包也会从官方源 / 华为云 / npmmirror 三镜像自动选最快；
2. 下载本仓库代码并整理成运行布局；
3. 安装内置 Python 3.12.10（只装在安装目录内，**不改系统设置**）；
4. 询问你的显卡：NVIDIA → 装 CUDA 12.8 版 torch；没有/不确定 → CPU 版；
5. 创建两个独立虚拟环境并装好全部依赖；
6. 下载基础模型与工具（rmvpe、小肥鱼声线、ffmpeg，约 270MB，全部按字节数校验）；
7. 生成启动入口 `启动RVC.bat`，并把 `卸载程序.bat` 一并放好。

磁盘需求：N 卡版约 12GB，CPU 版约 6GB。系统要求 Windows 10 1803 及以上。

## 卸载程序（新）

双击安装目录里的 `卸载程序.bat`：
- 会先停止正在运行的服务（3333 / 7865 / 8899 / 3002 / cloudflared）；
- 询问是否**保留个人数据**：翻唱成品、访客申请记录、网易云 Cookie
  会移到旁边的「安装目录_卸载备份」文件夹，其余全部删除；
- 两次确认，防止误删；删除在后台完成后窗口自动结束。

## 下载地址自定义

- 不想测速就固定线路：`一键安装.bat` 顶部 `GH_PREFIX=` 填加速前缀；
- 备选线路列表 `GH_LINE2~8`、Python 三个镜像、pip 源、torch 源全部可改；
- 重跑安装器是安全的（自动断点续装）。
