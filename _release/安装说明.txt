RVC 翻唱站 · 傻瓜式安装包 v1.3.2
====================================

只需要三步：

  第 1 步：把本压缩包解压到一个空间充足的盘（别放 C 盘根目录，
           NVIDIA 显卡版约需 12GB，CPU 版约 6GB）。
  第 2 步：双击「一键安装.bat」，会弹出 Windows 文件夹选择窗口，
           挑一个位置（也可以关掉窗口手动输入路径），
           有 NVIDIA 显卡按 G，没有按 C，然后等待。
           全程自动：测速选线、下载程序、安装 Python、
           安装依赖、下载模型。
  第 3 步：装完后双击「启动RVC.bat」，浏览器会打开监控面板
           （http://127.0.0.1:8899），在面板首页点「一键开启全部服务」
           就可以开始做翻唱了。

不想用了：双击安装目录里的「卸载程序.bat」，可选保留你的翻唱成品、
访客记录和网易云 Cookie（会移到旁边的备份文件夹）。

长效安装器（新）
----------------

本安装器是「长效版」：默认直接下载仓库 main 分支的最新代码安装。

所以以后程序更新了，你完全不用下载新的安装包：直接重跑同一个
「一键安装.bat」，就会自动装上最新版；已经装齐全的环境只补模型，
不会重装依赖（很快）。装完会显示「本次安装版本」。

想固定装某个旧版本：用记事本打开「一键安装.bat」，把顶部这一行
  set "RVC_TAG="
改成例如
  set "RVC_TAG=v1.0.3"
填了就锁定那个版本；锁定的版本下载失败时也会自动改用 main 分支，
不会卡住。

用文件夹选择窗口选安装位置（新）
--------------------------------

双击「一键安装.bat」后会弹出 Windows 标准的文件夹选择窗口：

  · 可以直接新建文件夹再选中它；
  · 窗口被挡住时去任务栏找一下；
  · 不想用窗口就直接关掉，改成手动输入路径（直接回车=默认位置）。

选好了会显示「安装位置」，确认无误后按回车继续。

下载线路测速
------------

安装开始时会自动测速 8 条 GitHub 线路（直连 + 7 个常用加速前缀），
打印每条耗时，并自动选中最快的。你也可以在提示时输入编号手动换线。

想强制固定某条线路：用记事本打开「一键安装.bat」，在顶部
  set "GH_PREFIX="  的等号后面填加速前缀（如 https://ghfast.top/ ），
  填了就跳过测速直接用它。
Python 安装包同样会从官方源 / 华为云 / npmmirror 三个镜像里自动选最快。

常见问题
--------

1. 下载失败 / 所有线路都测不通？
   检查网络后重跑安装器（会重新测速）；或在 bat 顶部 GH_PREFIX
   填你自己可用的加速地址。

2. 提示装好了但生成翻唱报错缺模型？
   个别大模型（hubert 本体、人声分离模型）因为来源不稳定，
   需要按安装结束窗口里打印的指引手动放一次，拿到直链后也可以
   运行：python 下载基础模型.py --url hubert=直链

3. 想用网易云的歌？
   双击 RVC-Data\RVCSVC\ncmapi\设置网易云Cookie.bat，按提示获取。

4. 想让朋友也能用？
   参见 RVC-Data\RVCSVC\docs\使用说明.md 的「公网访问」章节
   （面板一键开公网隧道，访客有独立申请入口和管理员审批）。

5. 想自定义所有下载地址？
   「一键安装.bat」顶部「下载地址配置区」可以改：仓库地址、要装的
   版本（RVC_TAG）、GitHub 加速线路列表、Python 镜像、pip 镜像源、
   torch 下载源。

6. 双击「一键安装.bat」窗口一闪就没了？
   现在不会了：安装器会把自己重新拉起，无论中途怎么出错，窗口都停着
   把报错显示出来，截图发出来就能定位。关键步骤同时写在同目录的
   _安装日志.txt 里（下载、装 Python、装依赖各阶段都有时间戳）。
   如果连窗口都不出现：先把压缩包解压再双击（不要在压缩软件预览窗口
   里直接点），再不行看杀毒软件有没有拦截记录。

7. 装到一半断了？
   直接重新双击「一键安装.bat」，已下载/已装好的会自动跳过。

8. 「文件夹选择」窗口弹不出来？
   不用管它：安装器会自动检测，弹不出就改成在黑窗口里手动填路径，
   界面上会有一个醒目的方框提示——粘贴完整文件夹路径回车即可
   （直接回车 = 装到默认位置），一样能装完。

常客免审批
----------

访客页有「白名单 · 免审批直通」卡片：写一段申请理由提交，站长（本机控制台）
批准后，这个人点歌就跳过审批直接进入制作队列。生效条件是「同一台设备 +
同一个网络」，换了设备或换了网络会失效，重新申请再批一次即可。

模型市场（新）
--------------

装好打开控制台（http://127.0.0.1:8899），右上角多了「模型市场」。

  · 在里面搜角色 / 歌手 / 关键词（miku、genshin、arknights…），
    或者点热门词；也能切到「合集包」，一个包里几十上百个声线；
  · 点「查看文件」选一个 .pth（必选）+ 配套 .index（可选，默认自动挑最像的）；
  · 点「下载并安装」：先给各条线路实测测速、挑最快的下，下完核对
    大小和 SHA-256，再用 torch 确认是 RVC 声线，全过才装进 WebUI；
  · 装完在控制台点「一键全部启动」（或重启 3333 后端），新声线就能用了。

模型版权归原作者，下载前看仓库里的 LICENSE；不要用真人声音模型做
商业化或公开传播。想手动装本机文件，控制台「模型导入」也还在。

----------------

1）模型市场可以自己加线路

   控制台 →「模型市场」（http://127.0.0.1:8899/market），页面上有
   「线路 / 自定义市场地址」卡片：

     · 填一个 HuggingFace 兼容的镜像或反代地址（要能访问 /api/models 和
       /<作者>/<仓库>/resolve/main/<文件>），点「先测一下」验证；
     · 点「＋ 添加」后它就跟内置线路一起参与测速，下载自动挑最快的；
     · 慢的线路点「停用」即可，自定义的还能删掉；
     · 地址只存本机 RVCSVC\_market_lines.json，不上传任何地方。

2）让 AI 帮你装

   用 WorkBuddy / Cursor / Claude Code 这类能跑命令的助手时，把仓库地址
   （https://github.com/panxian-AI/rvc-cover-station）发给它就行：
   它会读仓库里的一页纸 AI-INSTALL.md，跑一条命令装完，不用自己点。

   这条命令也可以自己粘进 PowerShell：

     $dir = "D:\RVC-Cover-Station"
     powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr -UseBasicParsing 'https://raw.githubusercontent.com/panxian-AI/rvc-cover-station/main/install/ai_install.ps1' -OutFile $env:TEMP\rvc_ai_install.ps1; & $env:TEMP\rvc_ai_install.ps1 -Dir '$dir' -Gpu auto"

     · 加 -DryRun 只验证线路和参数，不装东西（约 20 秒）
     · 装完最后一行是 JSON，ok:true 就是成功
     · 以后升级 = 重跑同一条命令（只换程序，不动模型和成品）

版本 1.1.2 新增（都是别人装机时真踩到的坑）
--------------------------------------------

1）启动不再「窗口一闪就没」

   以前的启动脚本假定「它旁边就是 RVC-Data」「runtime 下有 fix_paths.py」。
   装到别的盘、文件夹改过名、或者文件被挪动过，就会走进报错分支，而窗口
   一闪而过，什么原因都看不到。

   现在它会自己找根目录（本级 / RVC-Data / 上一级，以「含
   runtime\python312\python.exe 的那层」为准），装在哪都认；启动前先确认
   内置 Python 真能跑；任何一步失败都会把原因写在同目录的 _启动日志.txt，
   并停住等你按键，不再闪退。

2）安装时不再弹「此应用无法在你的电脑上运行」

   原因：下载 Python 安装包时只看了「网络有没有报错」，没看下到的究竟是
   什么。网络抽风时 CDN 会给回一段网页，照样存成 .exe 拿去运行，Windows
   就弹这个框。

   现在下完先校验大小（不到 10MB 判定为错误页），自动换 python.org /
   华为云 / npmmirror 三个镜像重试，不会再拿错误页当安装程序跑。

3）一键停止真的能停干净

   以前的「一键退出」有三个漏洞：同一端口上叠了多个进程时只杀得掉一个；
   公网隧道（cloudflared）不监听本地端口，按端口永远找不到，退出后面板关
   了公网地址还挂着；而且不管成没成功都照样退出面板——面板一关，你就再
   也点不到停止了。

   现在：端口上所有进程一起收、杀整棵进程树、两轮复查，停不干净就如实
   告诉你「端口 7865 仍被 PID xxxx 占着」并**不退出面板**，让你还能重试。
   另外新增了安装目录里的「停止RVC.bat」——不依赖面板，面板已经关掉也能
   按端口把残留清干净（加 --dry-run 可以只看不停）。

版本 1.1.3 新增（重要：修好「生成时报错 KeyError: 'data'」）
--------------------------------------------

症状：在监控台点「开始生成」，后台刷一段看不懂的堆栈，最上面是
      File "app_rvc.py", line 545, in convert
          data = response["data"][1]["name"]
      KeyError: 'data'
      和用什么声线无关，换哪个模型都一样。

原因：不是模型坏了，是「基础模型」的配置写错了。声线推理前要先用
      hubert 提取特征，而 hubert 的 config.json 里最后两层卷积核被写成了
      3，权重实际是 2，于是加载时报「尺寸不匹配」，推理直接 500。
      这个配置是安装器写的，所以新装的机器一律会踩到。

修法（三重保险）：
  1. 安装器写出的 config.json 改对了；
  2. 重跑安装器时会主动检查并纠正老安装里写错的这一项；
  3. WebUI 加载 hubert 时如果又遇到尺寸不匹配，会自己按权重把
     config.json 改对再重试一次（会把原文件备份成 config.json.bak）。

另外：监控台和后端现在不再把错误吞成 KeyError，而是直接告诉你
WebUI 日志里的真实原因（比如显存不足、模型不兼容），并给出排查方向。

如果现在就想让它跑起来：重跑一次 一键安装.bat 即可（不会重下模型）。
版本 1.1.4 新增（新声线装完，点一下就能用）
--------------------------------------------

症状：在模型市场把声线装好了，回监控台点歌却没有它，得自己重启整个程序。

原因：3333 后端（翻唱服务）的模型列表是启动时读一次的，往 assets\weights
      里丢新文件，跑着的进程不会自己回头看——不是坏了，是不知道有新东西。

现在：
  1. 模型市场「本机已装声线」标题右边多了「🔄 更新声线（重启后端）」，
     点一下让 3333 自己重启并重扫模型目录，约 30~90 秒，新声线立刻进
     点歌/翻唱列表。不用再翻「一键全部启动」，也不用关掉程序重开。
  2. 重启是「看着它关、再看着它起」才算成功；超时不算成功，失败会说是
     端口被占、Python 起不来还是显存不够，原始报错留在 RVCSVC\logs。
  3. 市场里装完会自动弹提示，并且记在浏览器里——中途关页面再回来还在，
     重启成功后自动消失。
  4. WebUI（7865）没在跑时点它会直接拦住，不让你干等超时。

注意：重启会中断正在跑的生成任务，先等手上任务出片再点。

更新完控制台如果还是旧界面：关掉面板窗口，重新双击「启动RVC.bat」。

版本 1.1.5 新增（长歌不再卡在「分离人声」这一步）
--------------------------------------------

症状：四五分钟的歌，点生成后在「分离人声伴奏」这步失败，日志末尾是
      numpy.core._exceptions._ArrayMemoryError: Unable to allocate 25.6 MiB

原因：分离人声要把整首歌的频谱一次性摊在内存里算。实测一首 4 分 40 秒、
      48kHz 立体声的歌，峰值提交内存到 6.5GB；机器余量不够时连 25MB 都
      申请不到。跟模型无关，自己导入的声线没坏，短歌也一直正常。

现在：
  1. 这一段的中间产物全部提前释放（缓冲区精度砍半、频谱直接按目标内存
     布局建、各频带用完即丢），峰值内存明显下降，同样的歌不再顶到天花板。
     音质没动：随机数据逐位比对最大差 0.000e+00，整段音频对比最大差只到
     16bit 的 1 个最低位。
  2. 内存真的不够时，不再把 numpy 堆栈甩给你，改成能照着做的提示（关掉
     吃内存的程序、换 3 分钟以内的歌、先「一键停止」再「一键全部启动」）。
     分离前日志里会多一行「分离前可用内存 xxx MB」，出问题看这个数就懂。
  3. 生成失败不再在安装目录留一整首歌的 wav（以前会留几十 MB）。
  4. 修好了「未找到匹配的 index（最高相似度: 0.32）」：WebUI 生成的 index
     文件名前面带一长串训练参数，把相似度拉到判定线以下，导致 index_rate
     其实一直没生效。现在归一化文件名再比，配套 index 命中 1.00，音色更准；
     不相干的 index 仍不会被误认。

更新完控制台如果还是旧界面：关掉面板窗口，重新双击「启动RVC.bat」。

版本 1.5.0 新增：数据备份与迁移
-------------------
控制台「高级设置」下面多了一张卡：数据备份与迁移。

这次加的是「退路」，不动推理链路，速度不受影响。

  1. 一键导出备份
     把访客记录、申请与队列、白名单、高级设置、成品库索引、已装声线清单
     打包成一个 zip，几秒钟就好（不勾音频只有二十来 KB）。
     勾上「连成品音频一起打包」会连同 covers 里的 mp3 一起带上，约 200MB+。
     文件存在 RVCSVC\_backup，浏览器也会下载一份；
     点「打开备份文件夹」可以直接拷到 U 盘或网盘。

  2. 导入分两种，动手前先看对照表
     选好 zip 后先只读校验，列出三列数字：
       项目        本机现在   覆盖导入后   合并导入后
     看清楚再决定：
       · 覆盖：本机数据整份换成包里的（换机器、重装、改坏了回滚用这个）
       · 合并：两边合起来按 id 去重，同一条取更晚的状态
               （两台机器各攒了一批记录要合并时用；同一个包导两次不会翻倍）
     必须勾「我确认要改写本机数据」才点得动。

  3. 导错了能退回来
     每次导入动手前，会先把本机现有数据整份导出一份
     （列表里带「导入前自动备份」标记），导错了直接再导回来就是原样。
     写入过程中任何一步失败，会自动把访客库/设置/成品索引原样写回。

  4. 坏包伤不到数据
     每份数据都带 sha256 校验；包里只认固定几个路径名，从不按包内声明的
     路径解压，所以 ../ 这种路径穿越写不出成品库以外的地方；
     更新版本做的包会提示先升级，别的程序的 zip 会被挡回去。

  5. 几个已知情况（都处理过了）
     · 备份里的单子正在「制作中」：恢复后改回「排队中」重新做一次，
       因为那单的进程在别的机器上，原样恢复会卡住队列。
     · 只导索引没带音频：成品库列表能看见，点开会提示缺文件。
     · 备份越积越多：自动存档留最近 20 份、手动导出的留 50 份，旧的自动删。

  从旧版更新：正常更新即可，数据格式一个字节没变，老的 guest_db.json 照用。
  更新完请重开一次面板（双击 停止RVC.bat 再启动，或用托盘菜单里的
  「停止服务并退出面板」），因为 dataio.py 是面板进程里的新模块，
  不重启就没有这张卡片。

  建议现在就导一份放着：不勾音频二十来 KB，几秒钟的事。

       设置  /console/settings  高级设置、模型市场入口、模型导入、数据备份与迁移
