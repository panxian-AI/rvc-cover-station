RVC 翻唱站 · 傻瓜式安装包 v1.1.0
====================================

只需要三步：

  第 1 步：把本压缩包解压到一个空间充足的盘（别放 C 盘根目录，
           NVIDIA 显卡版约需 12GB，CPU 版约 6GB）。
  第 2 步：双击「一键安装.bat」，会弹出 Windows 文件夹选择窗口，
           挑一个位置（也可以关掉窗口手动输入路径），
           有 NVIDIA 显卡按 G，没有按 C，然后等待。
           全程自动：测速选线、下载程序、安装 Python、
           安装依赖、下载模型。
  第 3 步：装完后双击「启动RVC.bat」，浏览器会打开监控面板
           （http://127.0.0.1:8899），在面板首页点「一键开启全部服务」
           就可以开始做翻唱了。

不想用了：双击安装目录里的「卸载程序.bat」，可选保留你的翻唱成品、
访客记录和网易云 Cookie（会移到旁边的备份文件夹）。

长效安装器（新）
----------------

本安装器是「长效版」：默认直接下载仓库 main 分支的最新代码安装。

所以以后程序更新了，你完全不用下载新的安装包：直接重跑同一个
「一键安装.bat」，就会自动装上最新版；已经装齐全的环境只补模型，
不会重装依赖（很快）。装完会显示「本次安装版本」。

想固定装某个旧版本：用记事本打开「一键安装.bat」，把顶部这一行
  set "RVC_TAG="
改成例如
  set "RVC_TAG=v1.0.3"
填了就锁定那个版本；锁定的版本下载失败时也会自动改用 main 分支，
不会卡住。

用文件夹选择窗口选安装位置（新）
--------------------------------

双击「一键安装.bat」后会弹出 Windows 标准的文件夹选择窗口：

  · 可以直接新建文件夹再选中它；
  · 窗口被挡住时去任务栏找一下；
  · 不想用窗口就直接关掉，改成手动输入路径（直接回车=默认位置）。

选好了会显示「安装位置」，确认无误后按回车继续。

下载线路测速
------------

安装开始时会自动测速 8 条 GitHub 线路（直连 + 7 个常用加速前缀），
打印每条耗时，并自动选中最快的。你也可以在提示时输入编号手动换线。

想强制固定某条线路：用记事本打开「一键安装.bat」，在顶部
  set "GH_PREFIX="  的等号后面填加速前缀（如 https://ghfast.top/ ），
  填了就跳过测速直接用它。
Python 安装包同样会从官方源 / 华为云 / npmmirror 三个镜像里自动选最快。

常见问题
--------

1. 下载失败 / 所有线路都测不通？
   检查网络后重跑安装器（会重新测速）；或在 bat 顶部 GH_PREFIX
   填你自己可用的加速地址。

2. 提示装好了但生成翻唱报错缺模型？
   个别大模型（hubert 本体、人声分离模型）因为来源不稳定，
   需要按安装结束窗口里打印的指引手动放一次，拿到直链后也可以
   运行：python 下载基础模型.py --url hubert=直链

3. 想用网易云的歌？
   双击 RVC-Data\RVCSVC\ncmapi\设置网易云Cookie.bat，按提示获取。

4. 想让朋友也能用？
   参见 RVC-Data\RVCSVC\docs\使用说明.md 的「公网访问」章节
   （面板一键开公网隧道，访客有独立申请入口和管理员审批）。

5. 想自定义所有下载地址？
   「一键安装.bat」顶部「下载地址配置区」可以改：仓库地址、要装的
   版本（RVC_TAG）、GitHub 加速线路列表、Python 镜像、pip 镜像源、
   torch 下载源。

6. 装到一半断了？
   直接重新双击「一键安装.bat」，已下载/已装好的会自动跳过。

常客免审批
----------

访客页有「白名单 · 免审批直通」卡片：写一段申请理由提交，站长（本机控制台）
批准后，这个人点歌就跳过审批直接进入制作队列。生效条件是「同一台设备 +
同一个网络」，换了设备或换了网络会失效，重新申请再批一次即可。

模型市场（新）
--------------

装好打开控制台（http://127.0.0.1:8899），右上角多了「模型市场」。

  · 在里面搜角色 / 歌手 / 关键词（miku、genshin、arknights…），
    或者点热门词；也能切到「合集包」，一个包里几十上百个声线；
  · 点「查看文件」选一个 .pth（必选）+ 配套 .index（可选，默认自动挑最像的）；
  · 点「下载并安装」：先给各条线路实测测速、挑最快的下，下完核对
    大小和 SHA-256，再用 torch 确认是 RVC 声线，全过才装进 WebUI；
  · 装完在控制台点「一键全部启动」（或重启 3333 后端），新声线就能用了。

模型版权归原作者，下载前看仓库里的 LICENSE；不要用真人声音模型做
商业化或公开传播。想手动装本机文件，控制台「模型导入」也还在。

卸载方式：双击安装目录里的「卸载程序.bat」（可选保留个人数据）；
本安装不会改动系统设置，Python 装在安装目录里。
