      已批准名单 
      
读取中…

    

    
批准后「同一台设备 + 同一个网络 + 同一把设备密钥」的申请自动入队、不再等你审批；换设备/换网络/换浏览器就失效，要重新批。每个身份每天最多 12 单、每小时 6 单、20 秒一单；出现多台设备或多个网络共用同一身份会自动暂停并在上方告警。「仅指纹」是老版本批准的，建议让对方重新申请一次绑上设备密钥，才防得住冒用。

  


  

    
验证码解锁请求 

    
读取中…

    
访客验证码连错多次会被临时锁定，他们可以在这里发请求请你提前解除。「同意」只解除当前这一次锁定：错误计数原样保留，之后再输错照样按阶梯锁定（1 / 3 / 10 分钟），不会从此豁免。拿不准就拒绝，让对方等锁定自己过期。

  


  

    
模型市场 

    

      🧩 去模型市场找声线
      
      线路检测中…
    

    
在公开免费模型站里搜声线（角色 / 歌手 / 合集包），点开看文件清单，选 .pth 和配套 .index 就能一键下载。下载前自动给各条线路测速挑最快的，下完核验大小 + SHA-256 + torch 结构，全过才装进 WebUI。装完在下面对应的下载卡片上点「🔄 更新声线」（一键重启 3333），新声线立刻可用。

  


  

    
模型导入

    
     允许覆盖同名文件
    
    
还没有导入过模型

    

    
会弹出 Windows 文件选择窗口，可按住 Ctrl 多选声线 .pth 和配套的 .index 索引。程序自动识别所选文件是否为 RVC 声线模型（读出采样率 / 版本 / f0 / 轮数），索引会自动和声线配对；确认合适后点「导入」装进 WebUI。装完直接点上面的 🔄 更新声线（一键重启 3333，约 30~90 秒），新声线就会出现在点歌列表——不用再去模型市场。管理/删除已装声线去 模型管理 页。
