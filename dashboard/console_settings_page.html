改完立即生效：同时制作数量马上下一次推进就按新值，翻唱参数对还没开跑的单生效
「同时制作数量」调大可以让多单并行，但每路都分显卡算力（单首会更慢），显存小于 8G 建议保持 1~2。其余是成品的默认翻唱参数，访客自己不用管。

模型市场

🧩 去模型市场找声线 线路检测中…
在公开免费模型站里搜声线（角色 / 歌手 / 合集包），点开看文件清单，选 .pth 和配套 .index 就能一键下载。下载前自动给各条线路测速挑最快的，下完核验大小 + SHA-256 + torch 结构，全过才装进 WebUI。装完在下面的导入卡片上点「🔄 更新声线」（一键重启 3333），新声线立刻可用。

模型导入

允许覆盖同名文件
还没有导入过模型
会弹出 Windows 文件选择窗口，可按住 Ctrl 多选声线 .pth 和配套的 .index 索引。程序自动识别所选文件是否为 RVC 声线模型（读出采样率 / 版本 / f0 / 轮数），索引会自动和声线配对；确认合适后点「导入」装进 WebUI。装完直接点上面的 🔄 更新声线（一键重启 3333，约 30~90 秒），新声线就会出现在点歌列表——不用再去模型市场。管理/删除已装声线去 模型管理 页。

数据备份与迁移

换硬盘、重装系统、手改 JSON 改坏了——都靠这份备份救回来。导出的 .zip 里是访客记录、申请与队列、白名单、高级设置、成品库索引（勾上「连成品音频」才含 mp3），外加一份已装声线清单，换机器后照着清单就知道缺哪个声线。导入前会自动把本机现有数据也存一份（列表里带 🕘 的那些），导错了直接再导回来。
