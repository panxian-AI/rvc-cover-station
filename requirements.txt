# 面板层依赖（dashboard/ + ncmapi/）—— 全部锁死版本
#
# 为什么写死 ==：这几个包都属于「上游一升级就改行为」的类型，而且都不是我们
# 能跟着改的（edge-tts 改 TTS 接口、gradio-client 改字段名、Pillow 改 API）。
# 不锁的话，某天 pip 顺手升一下，面板就可能起不来，或者「以前能用的功能突然
# 不行了」，而报错信息通常看不出跟升级有关。
#
# 升级姿势（不要直接改这里）：
#   1. 先在测试机  python -m pip install -r requirements.txt --upgrade
#   2. 跑 dashboard 下的 e2e 回归（至少 e2e_silent / e2e_market / e2e_dataio）
#   3. 全绿了再回来把新版本号写进这个文件，随版本一起发
#
# 核对：dashboard/deps.py 会在控制台「概览」页提示版本漂移
#       单独查：<python> dashboard/deps.py
#
